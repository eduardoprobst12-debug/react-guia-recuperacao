# React em Prática — Guia Interativo

Aplicação web educacional desenvolvida com React e Vite para revisão dos conceitos fundamentais de desenvolvimento web frontend.

## Funcionalidades

- **Guia de Estudos em Cards:** 8 módulos teóricos com explicações e exemplos práticos renderizados dinamicamente via `.map()`.
- **Análise de Erros Comuns:** Explicações detalhadas de falhas frequentes em React e suas soluções.
- **Controle de Progresso:** Marcação individual de conteúdos revisados com contador dinâmico (`0/8` a `8/8`).
- **Registro de Dúvidas:** Formulário interativo com validação de campos vazios via `.trim()` e atualização imutável de estado.

## Tecnologias Utilizadas

- React
- Vite
- JavaScript (ES6+)
- CSS3 (Grid e Flexbox responsivos)
- Git e GitHub
